# Security Policy

## Supported Versions
We currently support security updates for the following versions:
- `v1.0.x` and higher
- Pre-release (alpha/beta) versions are NOT guaranteed security patches.

## Reporting a Vulnerability

**DO NOT open a public GitHub issue for a security vulnerability.**

MeshNet takes security extremely seriously. If you have discovered a vulnerability in the cryptography (X3DH, Ratchet), routing (Sybil/Flooding), or local storage (SQLCipher), please responsibly disclose it by emailing **security@meshnet.net**.

You should receive a response within 48 hours. We ask for a 90-day embargo before you publish the vulnerability to allow us time to patch the network.
