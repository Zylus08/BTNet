# MeshNet

MeshNet is a production-quality, open-source Android framework for decentralized, offline mesh communication.

## Core Tenets
1. **Internet Independent**: Functions entirely without cellular or Wi-Fi infrastructure.
2. **End-to-End Encrypted**: All user data is encrypted using X3DH and the Double Ratchet algorithm.
3. **Hardware Agnostic**: Degrades gracefully across BLE, Wi-Fi Direct, and future transports (LoRa).
4. **Data Minimization**: Employs Bloom filters and strict TTLs to ensure metadata resistance.
